# PSS Junk Removal — Website Redesign

A modern, responsive, single-page marketing site for **PSS Junk Removal**, the operating brand of
PSS Property & Site Solutions LLC — same-day junk removal across Greater Los Angeles.

## Stack

Vanilla HTML, CSS and JavaScript. No build step, no dependencies, no environment variables.

## Files

| File | Purpose |
| --- | --- |
| `index.html` | Entry point — full page markup, meta tags, LocalBusiness JSON-LD |
| `styles.css` | Design system (tokens, components, responsive layout) |
| `script.js` | Mobile nav, sticky header, scroll reveal, active nav, quote form |

## Sections

Hero · Stats · About · Services (6) · Why Us · Pricing (4 tiers) · Testimonials · Areas Served · CTA · Contact + quote form · Footer
